# Contributing

This repository is not accepting general public contributions by default.

Issues and discussions may be used for questions, clarification, collaboration inquiries, and responsible feedback.

Pull requests are accepted only by prior written agreement.

Do not submit:

- derivative implementations
- private or third-party code
- proprietary algorithms
- confidential material
- generated recreations of private systems
- reverse-engineered structures
- patent-sensitive claims
- production integration patches

If you want to collaborate, contact the rights holder with who you are, what you want to do, what part of the repository it relates to, whether the use is academic, personal, nonprofit, commercial, or internal, and whether you need permission to quote, implement, adapt, teach, publish, integrate, lease, or evaluate.
