# Ownership Boundary

Ontologica OS is a public explanatory lens and synthetic reference harness.

It is not:

- the canonical private repository
- a source of truth for any private system
- a production runtime
- a public release of private algorithms
- a public release of private prompts
- a public release of private manifests
- a public release of private receipts
- a hardware control system
- a claim of equivalence to any private implementation

## Public artifacts

This repository may contain:

- conceptual documentation
- simplified schemas
- synthetic examples
- clean-room toy code
- noncanonical receipts
- noncanonical manifest examples
- didactic mathematical demonstrations

## Private artifacts intentionally excluded

This repository does not contain:

- production code
- exact mathematical kernels
- exact constants or thresholds
- canonical manifests
- real SHA lineage
- real receipts
- real runtime traces
- private prompts
- model routing heuristics
- hardware authority paths
- sealed release artifacts

## Boundary rule

Ontologica OS publishes the grammar of the architecture, not the machinery of the architecture.

The public repo may explain invariants, but it must not export capability. It must not be used as authority over a private canonical repository, and it must not receive automatic backflow from public examples into private implementation state.
