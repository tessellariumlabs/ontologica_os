# Ownership Boundary

Ontologica OS publishes a public vocabulary and synthetic reference surface.

It does not publish the machinery of any private system.

## Public scope

This repository may include:

- public-facing doctrine
- explanatory diagrams
- synthetic examples
- toy schemas
- simplified mathematical demonstrations
- noncanonical manifest examples
- noncanonical receipt examples
- noncanonical drift-guard examples

## Excluded private scope

This repository does not include or license:

- canonical private code
- exact mathematical kernels
- exact constants or thresholds
- private prompts
- private model-routing logic
- private manifests
- real SHA lineage
- real receipts
- real traces
- private evaluation corpora
- private runtime logic
- hardware authority paths
- sealed release artifacts
- private operator procedures

## No backflow

Public artifacts do not modify, substantiate, or define private canonical truth.

Nothing in this repository grants authority over any private repository, runtime, manifest, receipt, mathematical kernel, model roster, hardware path, or release process.

## Boundary sentence

The public repo may explain invariants, but it must not export capability.
