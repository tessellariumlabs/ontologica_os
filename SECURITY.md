# Security Policy

Ontologica OS is source-visible, rights-reserved, noncanonical, and nonproduction.

This repository is a public explanatory lens and synthetic reference surface. It is not a production implementation, not a security product, and not the canonical implementation of any private system.

## Reporting

Do not open public issues for security-sensitive reports.

For non-sensitive boundary questions, use the rights holder contact path listed in [COMMERCIAL.md](COMMERCIAL.md). For security-sensitive or rights-sensitive matters, do not include private, confidential, proprietary, or sensitive technical material in public threads.

## In Scope

Reports may be considered in scope when they identify:

- accidental exposure of private materials in this repository
- licensing or ownership-boundary ambiguity
- synthetic examples that imply unsafe production use
- files that appear to grant unintended rights
- examples that appear to bypass the noncanonical boundary
- public wording that could be mistaken for canonical implementation authority
- missing or inconsistent noncanonical labels on examples, schemas, or docs

## Out of Scope

The following are out of scope:

- attacks against toy examples
- production vulnerability claims
- requests for private manifests, prompts, receipts, model routes, hardware paths, or canonical implementation details
- attempts to reconstruct private systems
- model-training, benchmark, or dataset-use requests without written permission
- requests to bypass the rights-reserved license posture
- claims based on treating this repository as production software

## No Production Claim

Nothing in this repository should be deployed as production software or treated as an authority-bearing implementation.

Receipts, manifests, schemas, examples, drift guards, and mathematical-kernel demonstrations in this repository are synthetic and noncanonical.
