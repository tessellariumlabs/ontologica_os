# Sanitization and No-Backflow Policy

Ontologica OS is a public explanatory lens and toy reference harness. It is intentionally noncanonical.

## Sanitization principles

1. Preserve architectural vocabulary, not implementation machinery.
2. Replace private data with synthetic data.
3. Replace production code with toy examples.
4. Replace exact mathematical kernels with simplified demonstrations.
5. Replace real manifests and receipts with noncanonical examples.
6. Exclude prompts, routing heuristics, hardware paths, real model rosters, sealed archives, and private traces.
7. Avoid any artifact that can be mistaken for private proof.

## No-backflow policy

The public repository does not write into, modify, patch, generate, or substantiate any private canonical repository.

Public artifacts may inspire private hardening only through manual human review.

Forbidden:

- importing public toy code into canon without review
- treating public examples as private proof
- treating public schemas as canonical schemas
- treating public manifests as canonical manifests
- linking public issues to private truth state
- allowing public claims to define private architecture

## Release posture

Nothing in this repository should be treated as production-ready, canonical, promotable, or authority-bearing.
