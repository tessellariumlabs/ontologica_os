# Noncanonical Status

Ontologica OS is noncanonical by design.

The repository may be runnable and internally consistent, but it is still a public reference.

Noncanonical means:

- schemas are reference schemas
- manifests are reference manifests
- receipts are reference receipts
- math is a clean-room reference kernel
- tests verify public invariants only
- promotion decisions are demonstrative only

The public repo may explain invariants, but it must not export private machinery.
