# Mathematical Kernel

Ontologica OS assumes that language-model output is not enough to define durable state.

A mathematical kernel supplies deterministic transforms that can be replayed, hashed, compared, and receipt-bound.

The public reference kernel demonstrates:

- bounded symbolic units
- stable public fields
- deterministic projection
- replayable vector output
- manifest-addressed inputs and outputs
- drift comparison across versions

## Public abstraction

- `Tessera`: a bounded symbolic unit
- `Field`: a named public dimension
- `Projection`: a deterministic vector state
- `Manifest`: a hash-bound identity record
- `Drift`: measured difference between states
- `Receipt`: evidence about what was computed

The reference kernel is intentionally clean-room and noncanonical.
