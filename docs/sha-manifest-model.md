# SHA Manifest Model

Ontologica OS uses manifest-addressed artifacts to make identity and lineage explicit.

A public manifest records:

- input artifact references
- kernel identity and version
- output artifact references
- receipt references
- promotion status
- noncanonical status

A SHA does not prove truth. A SHA proves identity.

Truth still requires authority, review, and promotion.

The public reference uses SHA-256 and synthetic examples only.
